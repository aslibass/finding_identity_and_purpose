# Workshop Stages

This directory holds one file per workshop stage.

Each stage file should contain:
- the stage invitation
- the exercise tab instructions
- a visual example for the exercise
- the main truth-seeking question step (after exercise completion)
- follow-up prompts
- probes to move from abstraction to concrete evidence
- what to listen for

Question design guidance:
- Use multiple-choice options where possible so participants can pick the closest answer first.
- Include `None of these fit me yet` and `Other (my own words)` options.
- For deeper prompts, use a two-step format: select closest answer, then write one short concrete example.
- Keep questions in plain language so participants can recognise themselves before they have perfect vocabulary.
